# 先做减法，再做加法

演进系统时先移除复杂性，再构建。默认做减法。

把简化作为持续投资。最终设计应比开始时略简单、能力略强，而表面不变或更小。

- 先删后建

- 先削减再打磨（达到最小可用后再投入质量）

- 按观察到的使用设计，不按臆测的边缘情况

- 不添加规格未要求的推测性验证器、解析器或守卫

- 简化提示词（删除冗余指令和过多模板）

- 参考文件没有新内容时删除它，不要留下桩
