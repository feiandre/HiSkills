# 从第一性原理重新设计

整合变更时，不要把它拼接到现有设计上。重新设计，仿佛该需求从一开始就是基础假设。

- 阅读所有受影响文件，理解当前设计

- 问：“如果带着这个新需求从零编写，我们会构建什么？”

- 将变更传递到每处引用：类型、文档、示例、理由说明章节

- 思考整体重新设计，然后增量交付

这是将变更整合进现有设计时，保留未来选择价值的方法。
