# 探索者提示词模板

以此模板构建每个探索者子代理的提示词，填入占位符。

其他探索者正在并行调查同一子系统的不同部分。不要试图覆盖全部内容。专注分配给你的角度并深入探索。

## 输出

### 发现的组件

关键类型、服务、类和抽象。每项给出名称、文件路径，以及一句话职责说明。

### 流程

逐步说明执行流程。每步给出运行哪个函数／方法、位于哪个文件、做什么、接下来调用什么。包括步骤之间流动的数据。

### 读取的文件

列出探索过程中读取的每个文件，以便讲解者引用。

### 边界

此子系统与代码库其他部分相连的位置，以及输入输出。

### 不明显之处

任何令人意外、有历史原因或容易出错的地方。看起来应按一种方式工作、实际却按另一种方式工作的内容。

### 未决问题

任何无法完整追踪或理解的内容。诚实说明缺口。
