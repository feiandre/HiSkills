### 自动驾驶堆叠

运行 Autopilot-full 行动手册，但不合并。

1. **代替步骤 5，停在已验证。**每个 PR 在当前头部验证并绿灯后停止，将 PR 交给操作者。交接后，无操作者同意不得推送。每次循环提示词都点名本文件，使每次 tick 都看到不合并规则。

2. **只有 PR 基于另一 PR 时才堆叠。**这是步骤 3 的唯一例外。按 `playbooks/opening-a-pr.md` 的 **Size and stacks**，将 PR 基于另一 PR 的分支而非 trunk。代替步骤 2 变基到 trunk，每个 PR 变基到父 PR 分支，堆叠根变基到 trunk。较低 PR 出现新头部时重堆上方 PR，若重堆后 `git patch-id` 不变，该 PR 保留原裁决。

**回复：**逐个列出每个 PR 及裁决，代替合并内容。
