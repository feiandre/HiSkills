# Slack 对话

## 如何搜索

Slack MCP 工具各不相同。先确认可用哪个 Slack MCP 并检查工具模式。它可能需要 `mcp_auth`。身份验证失败时停止并报告缺口。

1. **按作者限定搜索。** PR 合并日期附近作者的 messages。大幅限制范围且常能发现关键信息。

3. **按 PR URL 搜索。** PR 被审查或讨论时，Slack 常链接它们。搜索 PR URL（或仅 `/pull/<number>`）。

4. **按错误字符串搜索。** 代码处理特定错误时搜索错误字符串，常能发现事故线程。

## 常见陷阱

- **频道历史考古的限制。** 很旧的信息可能因保留政策消失。某日期之前完全找不到内容时，注明保留断崖。

- **未搜索的私信。** 许多决定发生在不可搜索的私信中，你会漏掉。这是已知限制。

- **把推测性玩笑当“决策”。** Slack 很随意。“哈哈直接做吧”即使发生在提交前，也不是决策。寻找认真讨论。

- **单条消息脱离上下文。** 不看线程，单条消息常会读解不同。始终获取线程。

- **身份验证失败。** MCP 未验证时停止。不要编造发现。报告 Slack 无法搜索。
