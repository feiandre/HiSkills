# 限定范围重审提示词模板

修复轮后派发重审时使用本模板。重审者验证发现已处理，并检查修复差异是否引入新破坏。它不是全新审查——完整审查已发生。

**目的：**验证上一审查的每项发现已处理，且修复本身没有破坏任何内容。

```
Subagent (general-purpose):
  description: "重审任务 N 的第 R 轮修复"
  model: [MODEL — REQUIRED: choose per SKILL.md Model Selection; an omitted
         model silently inherits the session's most expensive one]
  prompt: |
    你正在重审一个任务的修复轮。先前审查产生了发现；实现者已尝试修复。
    你的工作是逐项裁决发现并检查修复差异——仅此而已。

    ## 任务

    阅读任务简报：[BRIEF_FILE]

    ## 待验证发现

    [FINDINGS]

    ## 修复

    阅读实现者报告（修复报告追加在末尾）：
    [REPORT_FILE]

    **修复基线：** [FIX_BASE_SHA]（上一审查看到的头部）
    **Head：** [HEAD_SHA]
    **差异文件：** [DIFF_FILE]

    差异文件只读一次——它包含修复提交、统计摘要及带周边上下文的
    修复差异。不要重复运行 git 命令。若差异文件缺失，自行获取：
    `git diff --stat [FIX_BASE_SHA]..[HEAD_SHA]` 及
    `git diff [FIX_BASE_SHA]..[HEAD_SHA]`。

    你的审查对本检出只读。不要以任何方式改变工作树、索引、HEAD
    或分支状态。

    ## 不要派发子代理

    亲自完成全部审查。绝不生成子代理审查差异一部分，绝不生成
    另一个审查者获取第二意见。此流程已提供工作的全部审查席位；
    你生成的审查者会重复一个席位且成本完整，其裁决不计。若差异
    对一次审查太大，自己分多次审查并在报告中说明。

    ## 范围

    范围是发现清单和修复差异。逐项裁决发现。检查修复本身引入的
    新问题。不要重审修复未触及的代码：若发现完全在修复差异之外，
    在“范围外观察”下报告——不阻塞任务，也不延长循环。所有任务
    完成后会进行广泛整分支审查。

    ## 测试

    实现者重跑了覆盖修改代码的测试，并将结果追加到报告文件。
    将报告视为未经验证的主张：确认修复报告点名覆盖测试并显示输出，
    并对照差异验证。不要重跑套件确认报告。只有阅读代码产生具体
    疑问且现有运行无法回答时才运行测试——且只运行聚焦测试，绝不
    运行整包套件。

    ## 输出格式

    最终消息就是报告本身：直接从第一项发现裁决开始。每行都是裁决、
    带 file:line 的发现，或你运行的检查——无前言、无过程叙述。

    ### 发现裁决

    按顺序对每项发现：
    - **[发现一句话]** — ADDRESSED | NOT ADDRESSED，附 file:line
      证据。“尝试过”不等于已处理：特定缺陷必须不再存在。

    ### 修复差异中的新破坏

    修复本身破坏或引入的任何内容，附严重程度
    （Critical/Important/Minor）及 file:line。干净则写“None”。

    ### 范围外观察

    完全在修复差异之外发现的问题。非阻塞；控制器记入账本供最终
    审查。没有则写“None”。

    ### 裁决

    **修复轮：** [全发现已处理，无新 Critical/Important
    破坏 | 仍有发现未解决]——列出未解决项。
```

**占位符：**

- `[MODEL]`——必需：按 SKILL.md Model Selection 选择审查者模型；小型修复差异的限定范围重审用低成本到中档

- `[BRIEF_FILE]`——任务简报文件（实现者使用的同一文件）

- `[FINDINGS]`——上一审查的 Critical/Important 发现及规范缺口，逐字复制，每项一条

- `[REPORT_FILE]`——实现者报告文件（追加了修复报告）

- `[FIX_BASE_SHA]`——上一审查看到的头部

- `[HEAD_SHA]`——当前提交

- `[DIFF_FILE]`——`bash scripts/review-package PLAN_FILE FIX_BASE HEAD` 打印的路径

**重审者返回：**逐发现裁决（ADDRESSED / NOT ADDRESSED）、修复差异中的新破坏、范围外观察及本轮裁决。
