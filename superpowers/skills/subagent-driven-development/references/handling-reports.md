# 处理未返回 DONE 的报告

属于 superpowers:subagent-driven-development。

**DONE_WITH_CONCERNS：** 实现者完成工作但标出疑虑。继续前阅读。涉及正确性或范围时先处理再审查；只是观察（如“文件变大”）则记录后审查。

**NEEDS_CONTEXT：** 实现者缺少未提供信息。补充上下文后重新派发。

**BLOCKED：** 实现者无法完成。评估阻塞：

1. 上下文问题：补充更多上下文，用同一模型重派。

2. 需要更多推理：换更强模型重派。

3. 任务太大：拆小。

4. 计划本身错误：裁定修正、记台账，将裁定随派发重派。

**绝不**忽略升级，或让同一模型无改动重试。实现者说卡住，说明必须有东西改变。
