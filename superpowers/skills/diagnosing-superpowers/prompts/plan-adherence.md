维度：计划遵循

恢复会话认同的计划，再将每个计划步骤映射到实际发生内容。此处“计划”是任何商定行动过程，不是 git 提交。

1. 查找商定计划：对话中商定的设计/计划（找人类回答“是/好/继续”前的助手文字）、会话期间写入的规格或计划文件（在 `docs/`、`plans/`、`specs/` 或人类指定文件中写入的工具调用）、案件文件确认含义的待办记录，或助手文字中的编号清单。用 `path:line` 引用每个步骤。

2. 标出计划与执行之间的结构事件：查找时识别的压缩、恢复、中止轮次和关联会话派发。记录行号；紧接这些事件后的计划漂移是单独发现。

3. 每个计划步骤找出执行它的工具调用和助手文字，或确认无人执行。报告：

- 跳过步骤（未找到执行；引用计划步骤）；

- 乱序执行（行号显示顺序）；

- 静默改变（执行不同于计划且助手未宣布；引用两者）；

- 发明步骤（完成任何计划步骤未覆盖的工作）；

- 结构事件后立即漂移（引用事件行及首个偏离动作）。

4. 无可恢复计划时，将其作为唯一发现，并说明检查过的行。
