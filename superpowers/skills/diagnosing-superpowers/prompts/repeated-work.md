维度：重复工作

找出会话做过不止一次的工作。

1. 将每次工具调用提取为 `(line, turn, tool, key)`，其中 `key` 是：读取／编辑／写入的文件路径；shell 调用的命令文本（删除尾随空白；保留完整命令）；子智能体派发的 `description` 加提示前 80 个字符；搜索查询。

2. 按 `(tool, key)` 分组，报告达到或超过阈值的组：

| 类别 | 阈值 | 豁免 |
   |---|---|---|
   | 读取、搜索 | 3 | |
   | 编辑 | 2 | |
   | shell 命令 | 2 | 状态检查和测试运行（`git status`、`ls`、`pwd`、测试运行器） |
   | 子智能体派发 | 相同描述 2 次 | |

3. 每组检查重复之间是否发生变化（对文件写入、压缩、人纠正）。说明属于哪种情况；编辑后重读不算发现，压缩后重读算归因于压缩的发现，中间没有任何变化的重读本身算发现。

4. 查找重新推导的决策：助手文字达到会话中已陈述的结论（相同文件、相同设计选择、相同待运行命令）。引用两处。

5. 每组一个发现，含首次与最后行号及次数。
