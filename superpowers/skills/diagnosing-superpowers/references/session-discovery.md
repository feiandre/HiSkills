# 查找会话历史

使用环境中的工具和信息，定位人类搭档指定的会话。知识可以提示去哪里找，但结果必须用实际历史验证。

使用平台提供的会话工具、配置存储、本地帮助、文档或有界文件系统检查。读取内容前先测量文件大小，并遵循 context-safety.md。环境指向归档或索引时检查它们。已有可用路径时无需再搜索。

用会话 ID、工作目录、时间戳和匹配对话内容确认身份。仅凭最近时间不能确认。区分指定会话、其子会话和无关候选；证据无法区分时询问缺失的识别信息。

每个文件系统来源都要从环境取得完整绝对路径，展开主目录简写和变量。案件记录与给人类搭档的查找答复使用同一路径。

根据观察到的记录或文档，确认调查所需记录字段含义。区分人类消息、注入消息、工具结果与父代理派发；将工具调用与结果配对；计算总量前确认使用计数器语义。不要从其他平台推断格式，也不要把缺失字段转成零。

在案件文件中记录确切来源、字段含义、证据位置、关联会话、排除的候选及未解决信息。后续读者应使用记录，不重复查找。历史缺失、不可访问或含糊时，说明具体限制并询问缺失路径、导出或识别信息。
