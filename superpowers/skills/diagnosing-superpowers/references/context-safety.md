# 会话转录的上下文安全

一条转录记录可能超过 1 MB 或嵌入完整历史。打印整条记录可能溢出正在诊断的会话上下文。控制器或子代理中的每位会话文件读取者，每次处理每个文件都必须遵守以下规则。

1. **读取前先测量。**

```bash
   wc -lc "$F"
   awk '{ if (length($0) > 100000) print NR, length($0) }' "$F"   # 过长的行
   ```

2. **绝不用 `cat` 或 `grep` 读取内容。**先获取行号和数量（`grep -n … | cut -d: -f1`、`jq -r '.type' | sort | uniq -c`），再从指定行提取小字段（`sed -n Np | jq -c '{…}'` 或 `| cut -c1-500`）。使用发现阶段为眼前来源建立的字段提取命令。

3. **将超过 500 字符的内容缩小。**若某条记录的命令返回超过 500 字符，收紧字段或切片。

4. **只读。**绝不修改、移动或删除会话文件。
