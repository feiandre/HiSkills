# 技能设计中的说服原则

## 概述

LLM 与人类一样会回应说服原则。理解这种心理有助于设计更有效的技能——目的不是操控，而是确保关键实践在压力下仍被遵循。

**研究基础：** Meincke 等（2025）在 N=28,000 个 AI 对话中测试了 7 项说服原则。说服技巧使遵守率提高一倍以上（33% → 72%，p < .001）。

## 七项原则

### 1. 权威

**是什么：** 对专业能力、资质或官方来源的遵从。

**在技能中如何运作：**

- 祈使语言：“你必须”“绝不”“始终”

- 不可协商的表述：“没有例外”

- 消除决策疲劳和合理化借口

**何时使用：**

- 强制纪律的技能（TDD、验证要求）

- 安全关键实践

- 已确立的最佳实践

**示例：**

```markdown
✅ 测试前写了代码？删除它。重新开始。没有例外。
❌ 可行时考虑先写测试。
```

### 2. 承诺

**是什么：** 与先前行动、陈述或公开声明保持一致。

**在技能中如何运作：**

- 要求声明：“宣布技能使用”

- 强制明确选择：“选择 A、B 或 C”

- 使用跟踪：为检查清单使用待办事项

**何时使用：**

- 确保技能真正被遵循

- 多步骤流程

- 问责机制

**示例：**

```markdown
✅ 找到技能时，你必须宣布：“我正在使用 [技能名称]”
❌ 考虑让伙伴知道你正在使用哪个技能。
```

### 3. 稀缺

**是什么：** 来自时间限制或有限可用性的紧迫感。

**在技能中如何运作：**

- 有时限的要求：“继续之前”

- 顺序依赖：“紧接 X 之后”

- 防止拖延

**何时使用：**

- 立即验证要求

- 时间敏感工作流

- 防止“我稍后再做”

**示例：**

```markdown
✅ 完成任务后，立即在继续之前请求代码评审。
❌ 方便时可以评审代码。
```

### 4. 社会认同

**是什么：** 遵循他人行为或公认规范。

**在技能中如何运作：**

- 普遍模式：“每次”“始终”

- 故障模式：“没有 Y 的 X = 失败”

- 建立规范

**何时使用：**

- 记录普遍实践

- 警告常见失败

- 强化标准

**示例：**

```markdown
✅ 没有待办跟踪的检查清单 = 步骤会被跳过。每次都会。
❌ 有些人觉得待办列表对检查清单有帮助。
```

### 5. 团结

**是什么：** 共享身份、“我们感”、群体归属。

**在技能中如何运作：**

- 协作语言：“我们的代码库”“我们是同事”

- 共同目标：“我们都想要质量”

**何时使用：**

- 协作工作流

- 建立团队文化

- 非层级实践

**示例：**

```markdown
✅ 我们是共同工作的同事。我需要你诚实的技术判断。
❌ 我错了的话，你也许应该告诉我。
```

### 6. 互惠

**是什么：** 回报所受恩惠的义务。

**如何运作：**

- 谨慎使用——可能让人感到被操控

- 技能中很少需要

**何时避免：**

- 几乎总是如此（其他原则更有效）

### 7. 喜好

**是什么：** 偏好与我们喜欢的人合作。

**如何运作：**

- **不要为了服从使用**

- 与诚实反馈文化冲突

- 制造谄媚

**何时避免：**

- 强制纪律时始终避免

## 按技能类型组合原则

| 技能类型 | 使用 | 避免 |
|------------|-----|-------|
| 强制纪律 | 权威 + 承诺 + 社会认同 | 喜好、互惠 |
| 指导／技术 | 适度权威 + 团结 | 强权威 |
| 协作 | 团结 + 承诺 | 权威、喜好 |
| 参考 | 仅清晰 | 一切说服 |

## 为何有效：心理学

**明确界线规则减少合理化：**

- “你必须”消除决策疲劳

- 绝对语言消除“这算例外吗？”问题

- 明确的反合理化反制堵住特定漏洞

**执行意图创造自动行为：**

- 清晰触发 + 必需行动 = 自动执行

- “当 X 时，做 Y”比“通常做 Y”更有效

- 降低服从时的认知负担

**LLM 具有类人心理：**

- 在包含这些模式的人类文本上训练

- 训练数据中权威语言通常先于服从

- 承诺序列（陈述 → 行动）被频繁建模

- 社会认同模式（大家都做 X）建立规范

## 道德使用

**正当：**

- 确保关键实践被遵循

- 创建有效文档

- 防止可预测失败

**不正当：**

- 为个人利益操控

- 制造虚假紧迫感

- 基于罪恶感的服从

**检验：** 如果用户完全理解该技巧，它是否服务于用户的真实利益？

## 研究引用

**Cialdini, R. B.（2021）。** *影响：说服心理学（新版与扩展版）。* Harper Business。

- 七项说服原则

- 影响力研究的实证基础

**Meincke, L.、Shapiro, D.、Duckworth, A. L.、Mollick, E.、Mollick, L. 与 Cialdini, R.（2025）。** 叫我混蛋：说服 AI 服从不当请求。宾夕法尼亚大学。

- 用 N=28,000 个 LLM 对话测试 7 项原则

- 说服技巧将服从率从 33% 提高到 72%

- 权威、承诺、稀缺最有效

- 验证了 LLM 行为的类人心理模型

## 快速参考

设计技能时问：

1. **它是什么类型？**（纪律、指导还是参考）

2. **我想改变什么行为？**

3. **适用哪些原则？**（纪律通常用权威 + 承诺）

4. **组合是否过多？**（不要七项全用）

5. **这合乎道德吗？**（是否服务用户真实利益？）
