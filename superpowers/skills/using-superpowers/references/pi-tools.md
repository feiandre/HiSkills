# Pi 工具映射

技能用动作表达（“派发子代理”“创建待办”“读取文件”）。在 Pi 上映射如下。

| 技能要求的动作 | Pi 对应项 |
| --- | --- |
| 派发子代理（`Subagent (general-purpose):` 模板） | 若可用，使用已安装的 `pi-subagents` 中的 `subagent` 等工具 |
| 任务跟踪（“创建待办”“标记完成”） | 若可用，使用已安装待办/任务工具；否则在计划或 `TODO.md` 跟踪 |

## 子代理

Pi 核心不提供标准子代理工具。可选配套 `pi-subagents` 较强，提供 `subagent`，支持单代理、链、并行、异步、fork 上下文和恢复/状态。无子代理工具时不要伪造 `Task` 调用；在当前会话顺序执行，或说明未安装可选能力。

## 任务列表

Pi 核心不提供标准任务列表工具。安装待办/任务扩展时使用其文档化工具；否则用 Superpowers 计划文件、Markdown 清单或仓库内 `TODO.md`。旧文档提到 `TodoWrite`，按上述任务跟踪动作理解。
