# RESOURCES.md 格式

`RESOURCES.md` 是本主题可信来源的精选集合。解释者的知识应来自这里，而非参数化猜测。智慧来自这里列出的社区。

## 结构

```md
# {主题}资源

## 知识

- [图书：Zatsiorsky 与 Kraemer 的 _The Science and Practice of Strength Training_](https://example.com)
  关于训练编排与适应的基础文本。适用于：周期化、恢复、强度区。
- [文章：Greg Nuckols（Stronger By Science）的 “How Much Should I Train?”](https://example.com)
  证据导向的训练量标志综述。适用于：每组肌肉每周组数目标。

## 智慧（社区）

- [r/weightroom](https://reddit.com/r/weightroom)
  高信噪比 subreddit，管理严防伪科学。适用于：计划批评、平台期排障。
- 本地：{健身房名称} 周二力量课
  适用于：举重训练的实时教练反馈。
```

## 规则

- **仅高可信度。** 优先原始来源、公认专家、同行评审工作和有强管理的社区。若某资源只是营销伪装成教育，不要加入。
- **为每个条目写注释。** 裸链接三个月后毫无用处。添加一行：它涵盖什么、何时使用。
- **按知识 / 智慧分组。** 对应 [SKILL.md](./SKILL.md) 中的理念。资源只出现在一组是可以的。
- **明确暴露缺口。** 若任务需要某领域但不存在好资源，写一个 `## Gaps` 部分列出缺失内容。这能推动未来搜索。
- **果断修剪。** 被证明错误、浅薄或偏离任务的资源应移除，而非埋藏。五个尖锐来源胜过三十个平庸来源。
- **记录社区偏好。** 若用户选择不加入社区，在此记录，避免未来会话持续提议。
