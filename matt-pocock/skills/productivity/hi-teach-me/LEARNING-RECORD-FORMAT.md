# 学习记录格式

学习记录位于 `./learning-records/`，按顺序编号：`0001-slug.md`、`0002-slug.md` 等。目录按需创建，仅在写第一条记录时创建。

学习记录相当于教学中的 ADR，记录不明显经验、关键洞见及会影响后续会话的已有知识，用于计算最近发展区。

## 模板

```md
# {所学或已确认内容的简短标题}

{1–3 句：学到了什么（或确认了什么已有知识），以及为何影响后续会话。}
```

这就是完整格式。学习记录可以只有一段。价值在于记录“现在已知这件事”及“为何它会改变下一步教学”，而非填满栏目。

## 可选章节

只有确实增加价值才包含；多数记录不需要。

- **状态** frontmatter（`active | superseded by LR-NNNN`，活跃或由某记录取代）：早期理解被证明有误并替换时有用。
- **证据**：用户如何展示理解（答对问题、完成练习、引用经验）；断言以后可能重审时有用。
- **影响**：为后续会话开启或排除了什么；不明显时值得记录。

## 编号

扫描 `./learning-records/` 中现有最大编号并加一。

## 何时记录

满足任一条件时记录：

1. **用户真正理解某项不简单内容**：不仅是接触过，而有正确使用概念的证据。它为下一步教学设定新起点。
2. **用户披露已有知识**：“我已经会 X。”记录下来避免重复教学，并记录声称的深度。
3. **纠正误解**：用户以前相信错误内容，现在明白原因。这类记录价值高，可预测相关主题的未来障碍。
4. **目标因学习而改变**：用户发现真正在意的事情不同。链接到 [[MISSION.md]] 并更新它。

### 不符合条件的内容

- 仅“讲过”的材料；覆盖不等于学习，应等待证据。
- 已在 [[GLOSSARY.md]] 以术语定义简洁记录的内容；不要重复。
- 逐会话活动日志；学习记录不是日记，而是决策级洞见。

## 取代关系

后续记录与先前记录矛盾（理解加深或修正）时，把旧记录标为 `Status: superseded by LR-NNNN`，不要删除；理解如何演变本身也是有用信号。
