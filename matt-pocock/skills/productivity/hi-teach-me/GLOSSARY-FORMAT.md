# GLOSSARY.md 格式

`GLOSSARY.md` 是此教学工作区的规范语言。所有讲解、练习和学习记录都应遵循其术语。建立术语表本身也是学习：把概念压缩成精确定义，能证明用户真正理解。

## 结构

```md
# {主题}术语表

{用一两句话说明本术语表覆盖的主题。}

## 术语

**Hypertrophy（肌肉肥大）**：
反复训练中由机械张力和代谢压力引起的肌肉增长。
_避免_：Bulking、getting big

**Progressive overload（渐进超负荷）**：
通过负荷、训练量或强度，随时间为肌肉系统性增加要求。
_避免_：Pushing harder、levelling up

**RPE（自觉用力程度）**：
对一组训练难度的 1–10 自评；10 为力竭，8 表示还剩两次。
_避免_：Effort score、intensity rating
```

## 规则

- **只有用户理解后才添加术语。** 术语表记录压缩知识，不是用户从头学习的词典；刚引入概念时，要等用户能正确使用再收录。
- **要有主张。** 同一概念有多个词时选最佳词，其余列为应避免的别名。这是语言压缩的方式。
- **定义紧凑。** 一两句；说明术语是什么，而非做什么或怎么做。
- **定义中使用术语表自身的词。** 术语一旦收录，其他定义中也优先使用，便于日后理解复杂概念。
- **自然分组时使用小标题** （如 `## Anatomy`、`## Programming`）；术语内聚时可用扁平列表。
- **明确标注歧义。** 若领域宽泛用法含糊，记录本工作区解释：“本工作区 set 总指正式工作组；热身另行记录。”
- **理解加深就修订。** 第一周写的定义到第六周可能错误，应原地更新，不留陈旧条目。
