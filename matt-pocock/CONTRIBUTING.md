# Contributing

# 贡献指南

<!-- zh-CN:end 8194c3aeedd0f2f8 -->

Every issue is judged against the bar in [`SCOPE.md`](./SCOPE.md). Read it first.

<!-- zh-CN:begin cb4788939c67f6aa -->

每个 issue 都按 [`SCOPE.md`](./SCOPE.md) 的标准判断。先阅读它。

<!-- zh-CN:end cb4788939c67f6aa -->

## Where each request goes

<!-- zh-CN:begin ff6457ec7a5e2ee7 -->

## 各类请求应去哪里

<!-- zh-CN:end ff6457ec7a5e2ee7 -->

| You have | Go to |
| --- | --- |
| A bug in a skill | [Bug issue](https://github.com/mattpocock/skills/issues/new?template=bug.yml) |
| A change to an existing skill | [Idea or feedback issue](https://github.com/mattpocock/skills/issues/new?template=idea.yml) |
| A question, or "how do I...?" | [Discussions: Q&A](https://github.com/mattpocock/skills/discussions/categories/q-a) |
| An idea for a new skill, or a skill to donate | [Discussions: Ideas](https://github.com/mattpocock/skills/discussions/categories/ideas) |
| Support for another harness or issue tracker | [Discussions: Ideas](https://github.com/mattpocock/skills/discussions/categories/ideas), after you read [`.out-of-scope/`](./.out-of-scope) |

<!-- zh-CN:begin 51d174fb757e84b2 -->

| 你有 | 前往 |
|---|---|
| 技能中的 bug | [Bug issue](https://github.com/mattpocock/skills/issues/new?template=bug.yml) |
| 对现有技能的变更 | [想法或反馈 issue](https://github.com/mattpocock/skills/issues/new?template=idea.yml) |
| 问题或“我该怎么做……？” | [讨论：问答](https://github.com/mattpocock/skills/discussions/categories/q-a) |
| 新技能想法或捐赠技能 | [讨论：想法](https://github.com/mattpocock/skills/discussions/categories/ideas) |
| 支持其他运行环境或 issue 跟踪器 | 阅读 [`.out-of-scope/`](./.out-of-scope) 后的[讨论：想法](https://github.com/mattpocock/skills/discussions/categories/ideas) |

<!-- zh-CN:end 51d174fb757e84b2 -->

Pull requests are open to collaborators only, so describe the fix in an issue instead.

<!-- zh-CN:begin 548b2e88319cb193 -->

拉取请求仅对协作者开放，因此在 issue 中说明修复即可。

<!-- zh-CN:end 548b2e88319cb193 -->

## Issues written with AI

<!-- zh-CN:begin 7c73211910f7f549 -->

## 用 AI 编写的 issue

<!-- zh-CN:end 7c73211910f7f549 -->

Agents are welcome to help, but you post the issue, so you own it:

<!-- zh-CN:begin 21cb54a7f69157a2 -->

欢迎智能体协助，但 issue 由你发布并负责：

<!-- zh-CN:end 21cb54a7f69157a2 -->

- **One problem per issue.** Several findings from one session are several issues, or none.

<!-- zh-CN:begin 06737e7b7f4923d5 -->

- **每个 issue 只写一个问题。** 一次会话中的多个发现就是多个 issue，或者不是 issue。

<!-- zh-CN:end 06737e7b7f4923d5 -->
- **Short.** If it does not fit on one screen, cut it.

<!-- zh-CN:begin 15245eba6bddea70 -->

- **简短。** 一屏容纳不下就删减。

<!-- zh-CN:end 15245eba6bddea70 -->
- **Repro first.** The steps that show the problem come before any analysis.

<!-- zh-CN:begin ce2d89eb17a5f037 -->

- **先复现。** 展示问题的步骤放在任何分析之前。

<!-- zh-CN:end ce2d89eb17a5f037 -->
- **No pasted specs.** No full proposals, plans, or rewritten `SKILL.md` files. Describe the problem; the fix is ours to design.

<!-- zh-CN:begin ffdc969ec786e5de -->

- **不要粘贴规格。** 不要完整提案、计划或重写后的 `SKILL.md`。描述问题；修复由我们设计。

<!-- zh-CN:end ffdc969ec786e5de -->
- **Not your project's issues.** If your agent files the specs or tickets for your own project here, it has the wrong repo. Run `/setup-matt-pocock-skills` in your project.

<!-- zh-CN:begin 925fe0181609c0ec -->

- **不要提交你项目的 issue。** 如果你的智能体把自有项目的规格或票提交到这里，它选错了仓库。请在你的项目中运行 `/setup-matt-pocock-skills`。

<!-- zh-CN:end 925fe0181609c0ec -->
