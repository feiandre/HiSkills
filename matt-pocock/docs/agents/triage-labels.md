# 分诊标签

<!-- zh-CN:end 00ca1e4b5bc1e3b9 -->

The skills speak in terms of five canonical triage roles. This file maps those roles to the actual label strings used in this repo's issue tracker.

<!-- zh-CN:begin 3142c50d4ff38400 -->

技能以五个规范分诊角色表达。本文件把这些角色映射到本仓库议题跟踪器实际使用的标签字符串。

<!-- zh-CN:end 3142c50d4ff38400 -->

| Label in mattpocock/skills | Label in our tracker | Meaning                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | Maintainer needs to evaluate this issue  |
| `needs-info`               | `needs-info`         | Waiting on reporter for more information |
| `ready-for-agent`          | `ready-for-agent`    | Fully specified, ready for an AFK agent  |
| `ready-for-human`          | `ready-for-human`    | Requires human implementation            |
| `wontfix`                  | `wontfix`            | Will not be actioned                     |

<!-- zh-CN:begin 1ff1a0c1bd5a9ce0 -->

| mattpocock/skills 中的标签 | 我们跟踪器中的标签 | 含义 |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage` | `needs-triage` | 维护者需要评估此议题 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可供 AFK 代理执行 |
| `ready-for-human` | `ready-for-human` | 需要人类实施 |
| `wontfix` | `wontfix` | 不予处理 |

<!-- zh-CN:end 1ff1a0c1bd5a9ce0 -->

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the corresponding label string from this table.

<!-- zh-CN:begin ef477d594323eaef -->

技能提到角色时（例如“应用可供 AFK 执行的分诊标签”），使用表中对应标签。

<!-- zh-CN:end ef477d594323eaef -->

Judge every issue against [`SCOPE.md`](../../SCOPE.md) before picking a state. Rejections close as "not planned".

<!-- zh-CN:begin 40b17f60cad9d0f8 -->

选择状态前，每个议题都按 [`SCOPE.md`](../../SCOPE.md) 判断。拒绝项以“not planned”关闭。
